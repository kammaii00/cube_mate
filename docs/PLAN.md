# Cube Mate 계획서

> 최종 수정: 2026-11-16 · 상태: 웹앱 MVP 구현 완료, 초등학생 대상으로 개편

## 1. 한 줄 정의
섞인 3x3 큐브를 카메라로 찍으면, 3D 화면이 "다음에 어느 면을 어느 쪽으로 돌릴지"를 한 단계씩 보여줘서 누구나 끝까지 맞출 수 있게 해주는 웹앱.

## 2. 확정된 결정
| 항목 | 결정 |
|---|---|
| 앱 이름 | Cube Mate |
| 형태 | 웹앱 우선. 반응이 있으면 같은 웹앱을 포장해 Play 스토어(Android)에 먼저 출시 |
| 언어 | 영어 기본 + 한국어 |
| 유료화 | 1회 구매 (스토어 출시 단계에서 도입, 웹 MVP는 무료) |
| 주 사용자 | 초등학생 |
| 범위 | 3x3 큐브만. 2x2·4x4, 타이머, 계정은 제외 |

## 4. 다음 단계
1. **실기기 검증:** 휴대폰에서 실제 큐브를 여러 조명으로 스캔해 인식 정확도 확인. 자동 촬영이 너무 빨리/늦게 되면 `scanner/autoCapture.ts`의 `CAPTURE_SETTINGS`를, 색 오인식이 잦으면 `scanner/classify.ts`를 조정.
2. **배포:** Firebase Hosting에 올리고 도메인 연결 (카메라는 HTTPS에서만 동작).
3. **초보자 테스트:** 지인 5명이 설명 없이 10분 안에 완성하는지 확인. 막히는 지점의 문구·화면 개선.
4. **검색 유입 준비:** 영어 랜딩 문구, 검색 노출용 설명 페이지.
5. **Play 스토어 출시:** 웹앱 포장(TWA) + 1회 구매 결제.

## 5. 위험 요소
* **카메라 색 오인식:** 스캔 뒤 반드시 확인·수정 화면을 거치게 했고, 검증이 불가능한 배치를 걸러낸다. 그래도 실기기 정확도는 아직 모른다.
* **큐브 방향 혼동:** 안내 시점을 고정하고 돌릴 줄과 화살표만 보여준다. 뒷면 회전은 윗면 맨 뒷줄의 화살표로만 표시되므로 아이들이 이해하는지 확인 필요.
* **자동 스캔 한계:** 표준 색 배치(흰색 맞은편 노랑, 빨강 맞은편 주황, 초록 맞은편 파랑) 큐브만 지원. 스티커 없는 큐브는 칸 사이 틈이 가늘어 자동 촬영이 안 될 수 있어 "직접 찍기"를 남겨 두었다.
* **수익성:** 무료 큐브 풀이 서비스가 이미 여럿 있을 가능성이 높다. 경쟁 조사는 아직 하지 않았다.
