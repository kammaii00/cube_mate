# Cube Mate 프로젝트 요약

## 💡 1. 프로젝트 개요
* **목적:** 섞인 3x3 큐브를 카메라로 찍거나 색을 입력하면, 3D 화면이 한 단계씩 돌리는 방법을 안내해 누구나 끝까지 맞추게 한다.
* **주요 타겟:** 초등학생 (큐브를 처음 맞춰 보는 아이들). 문구·버튼·속도 모두 초등학생 기준으로 맞춘다.

## 🛠 2. 기술 스택
* **Frontend:** React 18 + TypeScript + Vite (웹앱, 모바일 화면 우선)
* **Backend:** 없음 (모든 계산이 브라우저 안에서 이루어짐). 배포는 Firebase Hosting 설정(`firebase.json`) 포함
* **기타 도구:** Three.js(3D 큐브), cubejs(Kociemba 2단계 풀이 엔진, 웹 워커에서 실행), Vitest(단위 테스트)

## ✨ 3. 핵심 기능 목록
* **카메라 자동 스캔:** 큐브를 돌려 가며 보여주면 한 면씩 자동 촬영. 9칸이 모두 큐브 색이고(한 색뿐인 면은 칸 사이 틈도 보여야 함) 약 0.8초 멈춰 있을 때만 찍는다. 약간의 손떨림은 허용. 같은 면(가운데 색이 같거나 모양이 같은 면)은 다시 찍지 않는다. 면의 순서·방향은 상관없고, 가운데 색으로 어느 면인지, "실제로 가능한 큐브가 되는 조합"으로 각 면의 방향을 추론한다. 수동 촬영 버튼도 있음
* **촬영 현황 표시:** 여섯 가지 색 칸(흰·노·빨·주·초·파)이 찍은 면으로 채워지고 ✓ 표시. 이미 찍은 면을 보여주면 주황 테두리와 안내, 해당 칸 깜빡임. 찍은 면을 누르면 지우고 다시 찍기
* **직접 입력/수정:** 한 면씩 크게(칸 약 96px) 보며 색을 칠하고, 작은 전개도로 면을 오간다
* **상태 검증:** 빈 칸, 색 개수, 없는 조각, 중복 조각, 뒤집힘/돌아감/교환을 풀이 전에 잡아내고 의심 칸을 표시
* **빠른 풀이:** 22회전 이하의 풀이를 계산하고, 결과가 실제로 완성에 도달하는지 재확인
* **배우면서 맞추기 (8단계 수업):** 흰 꽃 → 흰 십자 → 1층 → 2층 → 노란 십자 → 노란 면 → 윗층 꼭짓점 → 마지막 조각. 단계마다 목표 그림·방법·새 공식을 먼저 보여주고, 조각 하나(미션)씩 "왜 이렇게 돌리는지"와 함께 안내한다. 넣을 자리는 항상 앞-오른쪽이 되도록 큐브를 통째로 돌리게 해(y 회전) 같은 공식만 반복하게 한다. 한 번 같이 해 본 공식은 "혼자 해 볼까요?"로 스스로 해 보게 하고, 단계가 끝날 때마다 그림과 비교해 확인한다. 평균 140회전
* **3D 단계별 안내:** 시점 고정(위·앞·오른쪽). 돌릴 줄만 선명하게 강조하고 화살표를 띄운 뒤 천천히 회전. 쉬운 문장("오른쪽 줄을 위로"), 이전/다시 보기/자동 넘기기
* **어린이용 디자인:** 마스코트 큐비의 말풍선 안내, 스티커 모양의 큰 버튼, 완성 시 색종이
* **한국어·영어:** 브라우저 언어로 자동 선택(기본 영어), 홈에서 전환

## 📂 4. 디렉토리 구조 및 역할
AI는 작업 시 아래 구조를 참고하여 파일을 탐색하고 수정해야 합니다.

```
📦 cube
 ┣ 📂 src
 ┃ ┣ 📂 core/       # 큐브 순수 로직 (화면·라이브러리와 무관)
 ┃ ┃ ┣ faces.ts     #   면·색·54칸의 위치 정의
 ┃ ┃ ┣ moves.ts     #   회전 규칙, 회전 기호 해석
 ┃ ┃ ┣ validate.ts  #   입력 상태 검증
 ┃ ┃ ┗ scramble.ts  #   무작위 섞기
 ┃ ┣ 📂 solver/     # 풀이 엔진 (solver.worker.ts: 워커, solverClient.ts: 화면용 창구)
 ┃ ┃ ┗ 📂 beginner/ #   배우면서 맞추기: lesson.ts(공식·수업 계획 구조), firstLayers.ts(1~4단계 규칙),
 ┃ ┃                #   lastLayer.ts(5~8단계), search.ts(공식 조합 탐색), pieces.ts(조각 찾기), index.ts
 ┃ ┣ 📂 scanner/    # 카메라 켜기·색 읽기(useCamera.ts), 색 계산(colorMath.ts), 54칸 분류(classify.ts),
 ┃ ┃                #   화면 분석(frame.ts: 9칸 색·칸 사이 틈), 자동 촬영 판단·중복 면 찾기(autoCapture.ts), 면 이름·방향 추론(orient.ts)
 ┃ ┣ 📂 render/     # 3D 큐브 (CubeScene.ts: Three.js 클래스, arrow.ts: 회전 방향 화살표, pointer.ts: 안 보이는 곳·조각·자리를 가리키는 이름표 화살표(안 보이는 조각·자리는 이름표 없이 큐브 밖에서 화살표만), 자리 칸은 분홍색 깜빡임, Cube3D.tsx: React 연결). 큐브는 손가락으로 끌어 돌려 볼 수 있고 손을 떼면 제자리로 돌아온다
 ┃ ┣ 📂 features/   # 화면별 폴더 (home, scan[ScanScreen, CaptureSlots], edit, guide[빨리 맞추기 안내], done,
 ┃ ┃                #   learn[배우면서 맞추기: frames.ts 장면 목록, LearnScreen, LearnPanels, FormulaStrip])
 ┃ ┣ 📂 widgets/    # 공통 UI: Mascot(큐비), Bubble(말풍선), Confetti(색종이)
 ┃ ┣ 📂 i18n/       # 문구 (ko.ts가 기준, en.ts는 같은 키를 가져야 함)
 ┃ ┣ App.tsx        # 화면 전환과 화면 간 데이터 전달
 ┃ ┣ main.tsx       # 시작점
 ┃ ┗ styles.css     # 전체 스타일
 ┣ 📂 tests/        # 단위 테스트 (회전, 검증, 풀이, 색 분류, 자동 촬영, 방향 추론)
 ┣ 📂 public/       # 아이콘, 웹앱 매니페스트
 ┗ 📂 docs/         # PLAN.md(계획서), APP_SUMMARY.md(이 문서)
```

규칙: 큐브 상태는 54글자 문자열(U→R→F→D→L→B 순, 빈 칸은 `?`)로 통일한다. 기준 방향은 흰색(U) 위, 초록(F) 앞. `core/`는 React·Three.js를 import하지 않는다.

## 🗺 5. 화면 구성 및 네비게이션
* **홈:** 시작 방법 선택, 언어 전환 -> 스캔 또는 색 확인·수정
* **스캔:** 큐브를 돌려 6면 자동 촬영 (카메라 불가 시 직접 칠하기로 안내) -> 색 확인·수정
* **색 확인·수정:** 한 면씩 크게 편집, 예시로 섞기, 검증, 풀이 방식 선택(빠르게/배우며) -> 풀이 안내
* **풀이 안내(빨리 맞추기):** 잡는 법 안내 후 회전을 하나씩 표시 -> 완성
* **수업(배우면서 맞추기):** 잡는 법 -> [단계 소개 -> 조각 찾기 -> 회전(이유·공식 줄) / 혼자 해보기 -> 단계 완성 확인] x 8 -> 완성(오늘 쓴 공식)
* **완성:** 결과 표시 -> 홈

## 🔄 6. 데이터 흐름 및 아키텍처
* 스캔(9칸 평균색 × 6면, `AutoCapture`가 촬영 시점 판단) → `resolveCube`(면 이름·방향 추론, 내부에서 `classifyScans`) → 54글자 상태 → `EditScreen`에서 수정 → `validate` → `solverClient`의 `solveFast` 또는 `solveLearn`(워커) → `Solution`(시작 상태·회전 목록·단계 번호) → `GuideScreen`이 `statesAlong`으로 단계별 상태를 만들고 `Cube3D`에 "회전 전 상태 + 회전"을 넘겨 애니메이션 재생.
* 전역 상태 관리 라이브러리 없이 `App.tsx`의 `useState`로 화면·큐브 상태·풀이를 보관한다.

## ▶️ 실행 방법
* 설치: `npm install` / 개발 서버: `npm run dev` / 테스트: `npm test` / 빌드: `npm run build` (결과물 `dist/`)
* 카메라는 `localhost` 또는 HTTPS 주소에서만 동작한다.
