# Cube Mate 프로젝트 요약

## 💡 1. 프로젝트 개요
* **목적:** 섞인 3x3 큐브를 카메라로 찍거나 색을 입력하면, 3D 화면이 한 단계씩 돌리는 방법을 안내해 누구나 끝까지 맞추게 한다.
* **주요 타겟:** 초등학생 (큐브를 처음 맞춰 보는 아이들). 문구·버튼·속도 모두 초등학생 기준으로 맞춘다.

## 🛠 2. 기술 스택
* **Frontend:** React 18 + TypeScript + Vite (웹앱, 모바일 화면 우선)
* **Backend:** 없음 (모든 계산이 브라우저 안에서 이루어짐). 배포는 Firebase Hosting 설정(`firebase.json`) 포함
* **기타 도구:** Three.js(3D 큐브), cubejs(Kociemba 2단계 풀이 엔진, 웹 워커에서 실행), Vitest(단위 테스트)

## ✨ 3. 핵심 기능 목록
* **카메라 자동 스캔:** 큐브를 돌려 가며 보여주면 한 면씩 자동 촬영. 9칸이 모두 큐브 색이고(한 색뿐인 면은 칸 사이 틈도 보여야 함) 약 0.8초 멈춰 있을 때만 찍는다. 약간의 손떨림은 허용. 같은 면(가운데 색이 같거나 모양이 같은 면)은 다시 찍지 않는다. 면의 순서·방향은 상관없고, 가운데 색으로 어느 면인지, "실제로 가능한 큐브가 되는 조합"으로 각 면의 방향을 추론한다. 수동 촬영 버튼도 있음
* **촬영 현황 표시:** 여섯 가지 색 칸(흰·노·빨·주·초·파)이 찍은 면으로 채워지고 ✓ 표시. 이미 찍은 면을 보여주면 주황 테두리와 안내, 해당 칸 깜빡임. 찍은 면을 누르면 지우고 다시 찍기
* **직접 입력/수정:** 한 면씩 크게(칸 약 96px) 보며 색을 칠하고, 작은 전개도로 면을 오간다
* **상태 검증:** 빈 칸, 색 개수, 없는 조각, 중복 조각, 뒤집힘/돌아감/교환을 풀이 전에 잡아내고 의심 칸을 표시
* **빠른 풀이:** 22회전 이하의 풀이를 계산하고, 결과가 실제로 완성에 도달하는지 재확인
* **큐브 배우기 섬 (꼬마 코스, 새 배우기 모드):** 실제 큐브 수업 방식(조각으로 보기 → 층별 풀이 → 진짜 섞은 큐브로 그 단계만 반복)을 따른다. 섬 0 조각 알기(화면만: 레벨마다 처음에 '조각 친구 소개' 애니메이션(PieceIntro: 가운데·모서리·꼭짓점·집) → 3D 칸 누르기 퀴즈. 모서리 찾기는 거의 맞춘 큐브, 꼭짓점 찾기·모서리 집 찾기는 섞인 큐브. 집 찾기는 두 가운데가 반짝이고 가운데·찾는 조각 말고는 회색, 집 자리를 눌러 맞힘. 문제는 'A과 B이 붙어 있는 조각' 문장+조각 그림(PieceIcon), 틀리면 누른 조각만 분홍 테두리 깜빡임, 끌어 돌린 방향 유지+돌려 보기/뒤집어 보기/처음 모양 버튼), 섬 1~3은 먼저 화면 연습(PuzzleScreen: 소개 애니메이션 → 화면 속 큐브를 버튼으로 돌려 반짝이는 조각 하나를 제자리로, 멀어지면 되돌리기 안내, 2번 멀어지면 눌러야 할 버튼 반짝임. 흰 꽃: 옆 꽃잎·아래 꽃잎·자리 비우고 올리기 / 흰 십자: 꽃잎 내리기·색 맞춰 내리기 / 1층: '💃 오른손 춤'(R U R' U') 버튼으로 춤 한 번·들어갈 때까지·데려와서 춤. 십자·1층 문제는 흰 조각과 가운데만 색, 나머지 회색) 뒤에 진짜 큐브 연습, 섬 1 흰 꽃·섬 2 흰 십자·섬 3 1층 진짜 큐브 연습(아이가 마구 섞고 노란색 위로 잡고 혼자 함 → 한 면만 카메라/칠하기로 확인, 십자·1층은 옆 색 ⭕ 확인). 도움: 방법 다시 보기(섬마다 화면 연습 소개 장면), 큐비한테 보여 주기(카메라 전체 스캔 또는 직접 칠하기(EditScreen onReady) → 초보자 풀이의 다음 조각 하나를 같이 돌리기. 1층 꼭짓점은 앞쪽 공식 없이 오른손 춤만 반복: solveLearn(state, {oneDance:true})). 퀴즈 레벨 3개, 연습 레벨 2개(같이 해 보기=도움 받아도 셈, 혼자 해 보기=보여 주기 없이만 셈), 레벨마다 3번 성공하면 별(결과 원 = 섬의 레벨 별, '다음 단계' 버튼), 별 받은 레벨이 있는 섬에 다시 들어가면 레벨 고르기(LevelPicker, 복습), 섬을 다 깨면 친구(뱅글이·모모·토토·꼬꼬) 구출+스티커 1장(1층 섬을 깨면 '1층 완성! 다음 섬은 준비 중이야!'), 섬 지도는 바다 지도: 위는 하늘 띠(뒤로·말풍선 고정), 아래는 화면 끝까지 바다(체크무늬 대신, html.at-sea). 모두 같은 모양의 모래섬을 지그재그 점선 뱃길로 잇고, 섬 옆 팻말에 배우는 모양(3×3 면 그림), 지금 할 섬 옆에 메인 큐비(변신 옷 포함)가 탄 배와 '▶ 레벨 이름', 잠긴 섬은 안개(팻말은 보임), 들어오면 지금 섬으로 자동 스크롤. 1층 섬 아래에 아직 없는 다음 섬 5개(2층·노란 십자·옆 색·꼭짓점·완성)를 흑백 '준비 중'으로 표시(창살 안에 물음표 친구, 누르면 '곧 열려!'). 지도에서 섬에 들어갈 때 레벨 고르기·단계 제목 카드도 바다 위에 띄우고 연습 화면부터 체크무늬, 섬 안 화면 제목 옆엔 그 섬 팻말 그림(IslandTitle). 홈에 구한 친구 표시. 같이 해 보기는 목표 카드(조각에만 색 이름표 '초록 꽃잎', 자리는 하늘색 깜빡임, 제자리에 거꾸로 낀 조각은 따로 안내) → 이유 → 동작 순서(`course/guide.ts`, `guideText.ts`). 흰 십자·1층 섬의 같이 해 보기는 앞 섬 단계(흰 꽃/흰 십자)를 먼저 혼자 하고 보여 준 뒤 이번 단계만 같이(StageCards). 새 단계에 들어갈 때는 가운데에 단계 제목 카드(섬·레벨 번호·그림·큰 제목, 음성 '다음은! …')를 2초(음성 끝까지 최대 3.5초) 띄움, 톡 누르면 넘김, 같은 단계 반복 땐 없음(LevelTitle). 기록 localStorage `cube-mate-course2`
* **(숨김) 배우면서 맞추기 (8단계 수업):** 색 확인 화면 버튼을 `SHOW_OLD_LEARN=false`로 숨김. 코드는 꼬마 코스 테스트가 끝날 때까지 유지. 흰 꽃 → 흰 십자 → 1층 → 2층 → 노란 십자 → 노란 면 → 윗층 꼭짓점 → 마지막 조각. 단계마다 목표 그림·방법·새 공식을 먼저 보여주고, 조각 하나(미션)씩 "왜 이렇게 돌리는지"와 함께 안내한다. 넣을 자리는 항상 앞-오른쪽이 되도록 큐브를 통째로 돌리게 해(y 회전) 같은 공식만 반복하게 한다. 한 번 같이 해 본 공식은 "혼자 해 볼까요?"로 스스로 해 보게 하고, 단계가 끝날 때마다 그림과 비교해 확인한다. 평균 140회전
* **3D 단계별 안내:** 시점 고정(위·앞·오른쪽). 돌릴 줄만 선명하게 강조하고 화살표를 띄운 뒤 천천히 회전. 쉬운 문장("오른쪽 줄을 위로"), 이전/다시 보기/자동 넘기기
* **돌리는 중 실수 알아채기(빨리 맞추기):** 매번 돌릴 때 돌린 뒤 보이는 곳에 도착하는 칸 하나를 분홍 테두리로 짚고 "빨간색이 어디로 가는지 봐!"(`guide/watchSticker.ts`). 전체의 1/3·2/3 지점(잡는 법 상기와 같은 때, 점검이 먼저)에 "너의 큐브도 이렇게 생겼어?" + "똑같으면 동그라미, 다르면 가위표를 눌러 줘!"(5초 머뭇거리면 안내 음성을 다시, 최대 2번) 큰 ⭕/❌ 그림 버튼(`CheckPrompt`, 음성 시작 알림 `voice.onVoiceStart`), 매 회전에 "내 큐브가 달라" 버튼. '달라'면 초록 앞면 → 흰 윗면(못 좁히면 빨간 면까지) 최대 3면만 카메라(`scan/FaceCamera`, 4방향 비교) 또는 직접 칠하기(`edit/FacePaint`)로 받아, 마지막 "맞아" 이후의 실수 후보와 맞춰 지금 상태를 찾는다(`solver/recover.ts`). 되돌리는 길과 새로 푼 길 중 짧은 쪽으로 안내를 다시 시작하고, 못 찾으면 받은 면을 채운 채 전체 스캔/입력으로 넘긴다(`guide/RecoverFlow.tsx`)
* **어린이용 디자인:** 마스코트 큐비의 말풍선 안내, 스티커 모양의 큰 버튼, 완성 시 색종이
* **완료 보상:** 완성하면 "짜잔~" 효과음(Web Audio 합성)과 색종이, 칭찬 5종 중 하나를 글자로 보여주고 "우와! 큐브를 다 맞췄어!" 음성(doneTitle→doneAgain)을 들려준다. 완성마다 스티커판(10칸)에 스티커 한 장, 10장을 채우면 큐비 변신(왕관→마법사→선글라스→파티 모자 순, 홈 화면 큐비도 같은 옷). 아이 이름을 넣은 상장을 만들어 사진(PNG)으로 저장(휴대폰은 공유 창). 기록은 이 기기 localStorage(`cube-mate-rewards`)에만 저장, 순위·시간 경쟁 없음
* **큐비 음성(한국어·영어):** 타입캐스트 녹음 mp3(한국어 `public/voice/<문구키>.mp3`, 영어 `public/voice/en/<문구키>.mp3`)를 `src/voice/voice.ts`의 `say()`/`useSay()`로 순서대로 재생. 화면 언어를 따라 `setVoiceLang()`으로 폴더를 고른다. 말풍선 큐비를 누르면 마지막 말 다시 듣기, 홈은 첫 터치("큐비를 눌러 봐!")로 자동재생 허용. 안내 화면은 회전 문구 음성 + 무작위 칭찬 10종(직전과 안 겹침), 전체의 1/3·2/3 지점에 1초 쉬고 잡는 법 상기(guideKeep). 녹음 원본은 `audios/`(git 제외)
* **홈 두 길:** '⚡ 빨리 맞추기 [5살부터]'(누르면 카메라로 보여 주기·색 직접 칠하기 버튼, 칠하기 화면 아래 버튼은 '▶ 맞추기 시작!')와 '🏝 배우며 맞추기 [초등학생]'(큐브 배우기 섬)
* **의견 보내기:** 홈 왼쪽 위 버튼 → 앱 안 입력 창(글 + 나이 칩, 어른 확인 없음) → 구글 스프레드시트 Apps Script 웹앱으로 저장(`features/home/feedback.ts`의 `FEEDBACK_URL`, 비면 버튼 숨김, 60초에 한 번)
* **한국어·영어:** 브라우저 언어로 자동 선택(기본 영어), 홈에서 전환

## 🗺 5. 화면 구성 및 네비게이션
* **홈:** 빨리 맞추기(-> 카메라 / 칠하기) 또는 배우며 맞추기, 의견 보내기, 언어 전환, 구한 친구 표시 -> 스캔 또는 색 확인·수정 또는 큐브 배우기 섬
* **스캔:** 큐브를 돌려 6면 자동 촬영 (카메라 불가 시 직접 칠하기로 안내) -> 색 확인·수정
* **색 확인·수정:** 한 면씩 크게 편집, 예시로 섞기, 검증, 풀이 방식 선택(빠르게/배우며) -> 풀이 안내
* **풀이 안내(빨리 맞추기):** 잡는 법 안내 후 회전을 하나씩 표시(1/3·2/3 지점에 똑같아? 확인) -> 완성 / '달라' -> 큐비랑 찾기(면 2~3개) -> 새 풀이로 다시 안내 또는 전체 스캔·입력
* **수업(배우면서 맞추기):** 잡는 법 -> [단계 소개 -> 조각 찾기 -> 회전(이유·공식 줄) / 혼자 해보기 -> 단계 완성 확인] x 8 -> 완성(오늘 쓴 공식)
* **큐브 배우기 섬:** 섬 지도 -> (별 받은 섬이면 레벨 고르기) -> 단계 제목 카드 -> 조각 알기 퀴즈·화면 연습(맞히면 다음 문제) / 진짜 큐브 연습(마구 섞기 -> 혼자 하기[방법 다시 보기 / 보여 주고(찍거나 칠해서) 한 조각 같이] -> 한 면 확인 -> 옆 색 확인) -> 결과(별·친구 구출) -> 한 번 더 하기 / 섬 지도로 가기 (결과에는 이번 레벨 점 3개 + '한/두 번 더 하면 별!')
* **완성:** 칭찬·색종이 → 스티커판(10장째면 변신 창) → 상장 받기(이름 입력 → 미리보기 → 사진 저장) / 한 번 더 -> 홈

## 🔄 6. 데이터 흐름 및 아키텍처
* 스캔(9칸 평균색 × 6면, `AutoCapture`가 촬영 시점 판단) → `resolveCube`(면 이름·방향 추론, 내부에서 `classifyScans`) → 54글자 상태 → `EditScreen`에서 수정 → `validate` → `solverClient`의 `solveFast` 또는 `solveLearn`(워커) → `Solution`(시작 상태·회전 목록·단계 번호) → `GuideScreen`이 `statesAlong`으로 단계별 상태를 만들고 `Cube3D`에 "회전 전 상태 + 회전"을 넘겨 애니메이션 재생.
* 전역 상태 관리 라이브러리 없이 `App.tsx`의 `useState`로 화면·큐브 상태·풀이를 보관한다.
